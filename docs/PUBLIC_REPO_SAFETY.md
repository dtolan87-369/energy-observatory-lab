# Public Repository Safety

This repository is public.

## Never commit

- API keys, passwords, OAuth tokens, private keys or credentials;
- personal/private records;
- private Dropbox or Drive exports merely for convenience;
- third-party files without redistribution rights;
- confidential product material before an explicit publication decision.

## Before adding external open-source material

Record:
- upstream repository;
- exact version / commit if material is copied;
- licence;
- attribution requirements;
- whether modified source must remain open;
- dependency licences.

Using a tool internally is not the same legal act as redistributing that tool or a derivative.

## Before release

Check:
- source provenance;
- evidence status;
- safety/use envelope;
- licence compatibility;
- whether renders are labelled as renders;
- whether claims match the evidence.

> PUBLICLY ACCESSIBLE ≠ PUBLIC DOMAIN.
