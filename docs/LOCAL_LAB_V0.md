# Observatory Local Lab v0

## Purpose

Use local/open tools for cheap, high-volume work while reserving frontier-model use for decisions where stronger reasoning materially changes the outcome.

> SPEND FRONTIER INTELLIGENCE WHERE IT CHANGES THE DECISION. AUTOMATE THE REST LOCALLY.

## Core loop

SOURCES → INDEX → LOCAL AI → GENERATION → FILTERING → CREATION TOOLS → DIGITAL / PHYSICAL TEST → EVIDENCE → PRODUCT / RELEASE → FEEDBACK → BACK INTO THE INDEX

## Evidence ladder

GENERATED → CAD CHECKED → PRINTED / BUILT → ASSEMBLED → TESTED → REPEATED → PRODUCT CANDIDATE

## Rules

- Generate broadly; verify selectively.
- If CAD can answer it, do not print it yet.
- If a coupon can answer it, do not print the whole part yet.
- Public on GitHub does not mean commercially reusable: check the licence first.
- The product should fund the next experiment.
