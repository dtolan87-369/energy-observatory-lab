# Human Tool vs Machine Tool #001

## Question

How does a physical tool change when human handling is removed from the design requirements?

## First object

A connector / alignment fixture.

## Version H — Human-first

Optimise for:
- fingers;
- obvious orientation;
- comfortable force;
- readable state;
- manual service.

## Version M — Machine-first

Optimise for:
- machine vision;
- self-centering;
- one valid orientation;
- repeatable robotic grasp;
- automatic seating verification;
- easy machine removal;
- measurable failure state.

## Candidate machine-native features

- AprilTag / fiducial reference;
- asymmetric self-keying geometry;
- lead-in chamfers / funnels;
- physical go/no-go seating witness;
- grasp datum independent of cosmetic form.

## Evidence

Compare:
- insertion time;
- alignment error;
- seating force;
- repeatability;
- failure rate;
- print time/material;
- human usability vs machine usability.

Do not claim originality of machine-oriented design in general. The Observatory contribution is the controlled comparative experiment.
