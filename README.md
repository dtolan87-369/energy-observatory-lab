# Energy Observatory Lab

**Making the Invisible Visible.**

This repository is the working engineering layer for the Energy Observatory: local/open AI, code, CAD briefs, games, experiment tooling, evidence templates, and release workflows.

## Core operating loop

```
SOURCES
→ INDEX
→ GENERATE BROADLY
→ FILTER CHEAPLY
→ CREATE / CAD / CODE
→ TEST DIGITALLY OR PHYSICALLY
→ PRESERVE EVIDENCE
→ IMPROVE
→ RELEASE / PRODUCT
→ FEEDBACK
→ BACK INTO THE INDEX
```

## Evidence ladder

```
MENTIONED ≠ DESIGNED ≠ GENERATED ≠ BUILT ≠ TESTED ≠ REPEATED ≠ EXPLAINED ≠ VALIDATED
```

For product work:

```
GENERATED → CAD CHECKED → PRINTED / BUILT → ASSEMBLED → TESTED → REPEATED → PRODUCT CANDIDATE
```

## Repository boundary

Keep this repo public-safe.

Do **not** commit:
- passwords, API keys, tokens or credentials;
- private personal material;
- unpublished third-party files that cannot legally be redistributed;
- raw Dropbox/Drive archive dumps.

Reference source locations instead.

## Working rules

- Generate broadly; verify selectively.
- Public on GitHub does not mean commercially reusable: inspect the licence.
- If CAD can answer it, do not print it yet.
- If a coupon can answer it, do not print the whole part yet.
- A conceptual scorecard can prioritise a test; it cannot win it.
- Resolved in a diagram is not resolved in hardware.
- The product should fund the next experiment.

See `docs/CONTINUATION_PROTOCOL.md` for how every substantial pass should improve the system rather than create another disconnected document.
