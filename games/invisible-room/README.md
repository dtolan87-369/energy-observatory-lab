# Invisible Room — Microgame Prototype

## Core idea

The player enters a room where something is happening but is not told the cause.

They use a small set of instruments, change one variable and infer the hidden phenomenon.

## Observatory grammar

```
NOTICE → PREDICT → PROBE → CHANGE → MEASURE → EXPLAIN
```

## First vertical slice

One room.
One hidden cause.
Three instruments.
One strong reveal.

Candidate first phenomena:
- magnetic field
- optical/refraction effect
- acoustic resonance
- thermal gradient

## Goal

Make the evidence method playable rather than turning it into a quiz.

## Engine

Godot is the current primary candidate.
