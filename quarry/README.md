# Open-Source Quarry

## Purpose

Find existing tools, libraries, mechanisms, demos and scientific software that can:

- save Observatory development time;
- become legitimate ancestors or components;
- support original products;
- expose gaps worth improving.

## Intake rule

```
FIND
→ VERIFY SOURCE
→ LICENCE CHECK
→ TEST
→ USE / ADAPT / HOLD / BLOCK
```

Public source code is not automatically commercially reusable.

## Preferred first-pass licences

Permissive licences such as MIT, BSD and Apache are usually easier to integrate into commercial workflows than strong copyleft or custom licences. Always inspect the actual upstream licence and dependencies.

## Current promising families

- parametric CAD: CadQuery, build123d, BOSL2
- FreeCAD automation / gears
- Godot + demo projects
- AprilTag machine-vision fiducials
- Ollama / local model infrastructure
- Qdrant retrieval
- n8n internal automation
- OpenPnP longer-term robotic fabrication

The Airtable **Energy Observatory Pipeline** is the structured source of truth for quarry status.
